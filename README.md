# Asteroids

Учебный проект курса AIDev: браузерная игра и практика разработки с агентами.
Исходный код создан для этого репозитория; лицензия — MIT.

## Запуск

Требуется Node.js 24 и npm.

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Сервер слушает только локальную машину.

```sh
npm run build
```

## Разработка

Создайте ветку от актуальной `main` и откройте PR. Для слияния нужны зелёный
CI и одобрение `@KalininVD`. Его собственные PR допускают обход только
требования ревью; CI обязателен для всех.

Начальная страница и инфраструктура готовы. Игровая логика, интерфейс,
миссии и настройки агентов добавляются отдельными PR.
