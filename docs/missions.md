# Как добавить миссию

Создайте отдельный JSON-файл в `src/missions/presets/`.
Назовите файл по `id`, например `quiet-orbit.json`:

```json
{
  "id": "quiet-orbit",
  "title": "Тихая орбита",
  "description": "Три медленных астероида для тренировки манёвров.",
  "seed": 73,
  "asteroidCount": 3,
  "asteroidSpeed": 0.7
}
```

Каталог подхватывает файлы автоматически; менять общий список не нужно.
`id` должен быть уникальным и состоять из строчных латинских букв, цифр
и разделяющих слов дефисов. Название и описание — непустые строки.
`seed` — целое число в безопасном диапазоне JavaScript.
`asteroidCount` — целое от 1 до 30.
`asteroidSpeed` — конечное положительное число; 1 означает базовую скорость.

Миссия задаёт стартовые параметры волн. Игровая логика получает только
параметры симуляции; названия и описания использует интерфейс.
Внутри одного полёта миссия фиксирована. После завершения можно выбрать
другую или повторить ту же с исходным seed.

## Проверка

```sh
npm test
npm run build
npm run test:e2e
```

Модульные тесты читают все JSON-файлы миссий и проверяют их контракт.
В браузере убедитесь, что миссия появилась в списке, её описание соответствует
поведению, а после рестарта применяются исходные параметры.

Для PR достаточно нового файла и описания проверенного сценария. Изменения
общего кода нужны, только если вы добавляете новую механику или параметр.
