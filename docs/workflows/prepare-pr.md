# Подготовка PR

1. Прочитайте CONTRIBUTING.md и проверьте текущую ветку, статус и дифф.
   Включайте в коммит только файлы задачи.
2. Выполните проверки из [verify-change](verify-change.md), подходящие
   изменению. Для PR обязательна локальная команда `npm run check`.
3. Напишите заголовок на английском и описание на русском:
   причина, итоговое поведение, выполненные проверки. Используйте шаблон PR.
4. Если публикация входит в запрос, отправьте рабочую ветку и откройте
   либо обновите PR в `asteroids-developers/asteroids` с базой `main`.
   При работе из форка явно проверьте владельца исходной ветки.
5. После публикации прочитайте сохранённые заголовок и описание, проверьте
   актуальный head commit и результаты CI именно для него.

При конфликте используйте процедуру из CONTRIBUTING.md. Сохраните
смысл обоих изменений и повторите затронутые проверки после слияния веток.

Слияние PR выполняйте только в рамках разрешённой задачи.
Для студенческого PR требуется актуальное одобрение @KalininVD.
Исключение из правила ревью разрешено применять только к PR с автором
KalininVD; это не отменяет обязательный CI. Не создавайте фиктивное ревью
и не изменяйте защиту ветки ради слияния.
