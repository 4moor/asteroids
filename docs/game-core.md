# Игровая симуляция

Модуль `src/game/core.js` не зависит от браузера.

- `createGame({ seed, asteroidCount, asteroidSpeed })` создаёт новую игру.
- `stepGame(state, input, dt)` возвращает следующее состояние, не изменяя вход.
- `input` содержит логические `left`, `right`, `thrust`, `fire`.
- `dt` задаётся в секундах; рекомендуемый фиксированный шаг — 1/60.
  Большие значения ограничены 0,05 с, отрицательные и нечисловые отклоняются.
- Координаты — логические пиксели поля 960×640, скорости — пиксели/с.
- `status` принимает `playing` или `gameover`; UI отвечает за меню и паузу.
- Случайность хранится в состоянии: одинаковые seed и входы дают одинаковый результат.

Три жизни; очки за большие/средние/маленькие астероиды — 20/50/100.
После столкновения корабль неуязвим две секунды. Новая волна появляется
после уничтожения всех астероидов; число объектов ограничено 30.
Рестарт вызывает `createGame` с исходными параметрами.

Проверка: `npm test`.
