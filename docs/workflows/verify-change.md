# Проверка изменения

Работайте из корня репозитория. Если зависимости ещё не установлены,
выполните `npm ci`. Команды ниже используют закреплённые зависимости.

| Изменение | Проверки |
|---|---|
| Симуляция | Тест изменённого поведения, затем `npm test`; для PR также браузерные сценарии |
| Миссия | `npm test`, `npm run build`, запуск выбранной миссии в браузере |
| Интерфейс, ввод, HUD | `npm run check` и `npm run test:e2e` |
| Только текст или настройки агента | Ссылки, синтаксис и обнаружение изменённых файлов; для PR также `npm run check` |

Чтобы проверить один сценарий симуляции:

```sh
node --test --test-name-pattern="collisions" tests/unit/core.test.js
```

Чтобы проверить один браузерный сценарий:

```sh
npm run test:e2e -- --grep "pause"
```

Для новой механики проверьте основной сценарий и относящийся к ней
граничный случай. Для визуального изменения посмотрите страницу в браузере.
Скриншот подтверждает отображение; состояние симуляции проверяйте тестом.

`npm run check` объединяет модульные тесты и сборку. Браузерные проверки
требуют предварительной установки Chromium по README.
При изменении тестового API проверьте его отсутствие в production-сборке.

Перед передачей результата выполните `git diff --check`.
Сообщите, что проверяли и что осталось непроверенным. Успешный запуск
одного теста не подтверждает работу остальных сценариев.
